## Entry plan

- **pdgaCourseId** = the PDGA node ID (e.g., Bartholomew Park = `25329`), found in the course page source; null when not on PDGA (Zilker).
- **PDGA ratings ≠ UDisc ratings** — use UDisc for `rating`/`reviewCount` per the workflow; PDGA ★ here is for prioritization only.
- **Batch 1 (marquee, QA-relevant):** Roy G. Guerrero, Circle C, MetCenter, Wells Branch, Bartholomew, Harvey Penick, Benbrook Ranch, Old Settlers, Cat Hollow, Live Oak Brewing, East Metro Park, Northtown, Flying Armadillo (Big + Mini), WilCo, Wong Way Woods.
- **Batch 2:** remaining 18-hole + notable 9-hole public courses.
- **Batch 3:** church/school/brewery 9-holers and outlying towns (Taylor, Elgin, Lockhart, Smithville, Spicewood).
- **Skip:** Wildflower Micro (<6 holes); Richard Moya temporary unless confirmed open.
- **Sequencing rule:** `npm run check:courses` after each batch; statuses land in Review until photos + `parSource` are resolved (photo policy is the current gate).
