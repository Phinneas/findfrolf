# Top-50 Candidates (hole-by-hole priority list)

Working list for the top-50 hole-by-hole task (see `docs/top-50-hole-data-plan.md`). ~3–5 courses per city across the 15 MVP cities, ranked by local importance proxy in order: UDisc review count → UDisc play count → PDGA rating → best-of lists. **No invented numbers** — unverified proxies are marked.

Legend — Specs: `PDGA ✓` = course-level specs verified from the PDGA page; Hole data: `—` = none yet, `to-source` = needs scorecard/UDisc/on-site, `done` = entered and check-script-clean.

**Count:** 64 candidates across all 15 cities — **kept in full** (supersedes the task card's "top 50"; no trim). Review counts were extracted live from UDisc page JSON-LD (`ratingCount`) in this session; the two exceptions are flagged. Research completed via PDGA directory walk + live UDisc pages.
